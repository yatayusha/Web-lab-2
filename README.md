# Web-lab-2

# Структура
- `index.html` — только каркас и подключение скрипта
- `script.js` — вся разметка страницы и логика
- `style.css` — стили и адаптивность (flex, grid, media queries)

# Логика
- добавление, удаление и редактирование задач (текст и дата)
- отметка о выполнении
- поиск по названию, фильтр по статусу, сортировка по дате
- изменение порядка перетаскиванием (drag-and-drop)
- сохранение в localStorage
